# Zenovy Growth Website

Premium marketing website for **Zenovy**, a growth infrastructure company serving high-ticket residential home-service contractors.

The site is built around Zenovy's **Quiet Performance Luxury** system: Obsidian-led surfaces, Ivory editorial breaks, Champagne Gold signal accents, Deep Forest transitions, Cormorant Garamond display typography, and Manrope functional UI typography.

## Start here for future agents

Read [`AI_HANDOFF.md`](./AI_HANDOFF.md) before making changes. It documents:

## Commands

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
pnpm preview
```

## Routes

- `/` — homepage
- `/how-it-works` — six-stage methodology and Growth Architecture
- `/results` — Marakas Pizza evidence page
- `/about` — founders and operating principles
- `/faq` — searchable categorized FAQ
- `/diagnostic` — Growth Diagnostic booking shell
- `/diagnostic/briefing` — post-booking preparation page
